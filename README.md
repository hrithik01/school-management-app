# Brilliant Global School Management System

Local SvelteKit and SQLite app for Brilliant Global School, Bhungra.

## Start the app

```bash
pnpm install
pnpm run dev
```

Open the URL shown in the terminal, usually http://localhost:5173.

## Stack

- SvelteKit
- SQLite via better-sqlite3
- File-based routing and API endpoints under src/routes

## Features

- Homepage with date, school identity, to-do checklist, and live master balances
- Student management with income-linked fee tracking
- Income tracking with student-aware fee entries
- Expense tracking with employee and vehicle linkage
- Masters for opening balances, towns, employees, and vehicles
